Interactive Solar System Portfolio:

This project is a virtual cv/personal portfolio built with Three.js. Instead of a traditional website, the cv is presented as a miniature solar system where each planet represents a different section of the site.

Users can hover over planets and click to zoom in and view information through a display panel.

Features:
3D solar system built with Three.js
Orbiting textured planets
Animated sun and star field
Planet hover effects (like enlargement of planet and orbit path lighting up)
Smooth camera transitions
Information panel for each section
Downloadable CV
GitHub, LinkedIn and email links

Built With:
HTML
CSS
JavaScript (ES Modules)
Three.js

Running the Project:

Clone the repository:

git clone https://github.com/jc-thomson/virtual-cv.git

Open the project with a local web server such as the VS Code Live Server extension. 

or

open the Github Pages page at: https://jc-thomson.github.io/virtual-cv/

The project uses JavaScript modules so opening index.html directly from the file system will not work.
